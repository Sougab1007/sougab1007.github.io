✨ What is pyxaf?

pyxaf is a Python library that helps you read and validate Dutch Auditfile Financieel (XAF) files. These files are used in accounting and bookkeeping in the Netherlands. The library supports all versions: XAF 4.0, 3.x, CLAIR2, and ADF. It is designed to be easy to use, even if you are not a programmer. It works on Windows and other operating systems.

With pyxaf, you can open audit files, check if they are valid, and extract financial data. It uses exact Decimal money to avoid rounding errors. It has zero dependencies, meaning you don't need to install extra packages. It also supports streaming, so you can process large files without running out of memory.
